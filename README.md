# Jarvis Feedback

This public repository collects user-facing feedback for Jarvis binary releases.

Use this tracker for:

- Bug reports that are safe to discuss publicly.
- Feature requests.
- UX feedback.
- Report IDs generated by the Jarvis Web or macOS app feedback panel.

Do not post:

- API keys, tokens, passwords, or credentials.
- Full logs.
- Private chat/session content.
- Local filesystem paths that include your real username.
- Security vulnerabilities.

When Jarvis generates a private diagnostic report, it returns a `Report ID`.
Paste only that ID into the public issue. Screenshots, logs, stack traces, and
diagnostic payloads remain private unless you explicitly choose to share them.

Security reports should be sent through a private channel, not this public issue tracker.
